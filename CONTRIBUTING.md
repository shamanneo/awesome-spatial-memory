# Contributing to Awesome Spatial Memory

Thank you for helping curate research on spatial memory.

## What belongs here?

We prioritize work that studies the **representation, maintenance, update, retrieval, or evaluation of spatial information across observations**. Especially relevant topics include streaming scene memory, recurrent spatial state, object permanence, and memory-guided spatial reasoning.

General-purpose 3D reconstruction, tracking, or embodied-agent papers should be placed in **Background and Related Resources** unless they explicitly contribute a spatial memory mechanism or evaluate memory retention.

## Proposing a paper

Before opening a pull request, please:

1. Check that the paper is not already listed.
2. Choose the most relevant existing category. If no suitable category exists, propose a new one in the pull request description.
3. Add the paper under its primary category, keeping entries ordered by the displayed publication year (newest first). Use a verified venue and year when known; otherwise use the preprint year.
4. Include a stable paper link and a short, factual sentence explaining **why it matters for spatial memory**.
5. Add links to official code or the project page only when confirmed.
6. Explain the paper's contribution to memory in the pull request description.

Preferred format:

```markdown
- **Paper Title** — *Venue Year* · [Paper](https://arxiv.org/abs/xxxx.xxxxx) · [Code](https://github.com/example/repository) · [Project](https://example.org)  
  One concise sentence explaining the paper's contribution to spatial memory.
```

Use **Year** if the venue is not verified yet. Omit unavailable links instead of inserting placeholders. For dedicated datasets or benchmark portals, use **[Benchmark]** rather than **[Paper]** when linking directly to a resource page.

Please avoid unverifiable claims about performance, unsupported superlatives, duplicate entries, and generic summaries copied from abstracts. Entries may belong to multiple methodological themes; list them once under the most relevant primary category and explain cross-category relationships in the PR if useful.

Corrections to titles, links, venues, and categorization are also welcome.
